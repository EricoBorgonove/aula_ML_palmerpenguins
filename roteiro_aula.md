# Roteiro da aula

1. Apresentação da base Palmer Penguins
2. Carregamento e exploração dos dados
3. Tratamento de valores ausentes
4. Preparação de features e pipeline
5. Treinamento do modelo RandomForest
6. Avaliação: acurácia, matriz de confusão, métricas
7. Interface com Streamlit e interação
8. Exercícios práticos e variações (feature engineering)

Notas:
- Cada tópico deve ter exemplos práticos e exercício curto.
- Estimativa: 60–90 minutos dependendo do aprofundamento.

Tarefas futuras:

- Demonstrar cross-validation e busca de hiperparâmetros
